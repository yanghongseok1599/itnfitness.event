# 강력한 후킹 멘트 모음

## 업종별 후킹 멘트

---

### 피트니스/헬스장

#### 2인 등록 강조
```
"혼자 등록하면 손해입니다"
친구랑 오면 월 45,000원 + 현금 4만원 캐시백
12월 안에 오세요. 이 가격 다신 없습니다
```

#### 작심삼일 공략
```
"작심삼일? 같이 하면 달라집니다"
2인 등록 월 45,000원 / 미션하면 4만원 현금 할인
새해 첫 약속, 지금 잡으세요
```

#### 숫자 임팩트
```
월 45,000원으로 1년 운동하는 법
2인 등록 + 미션 4개 = 현금 4만원 돌려드림
운동복, 수건, 락커 전부 공짜
```

#### 직설형
```
헬스장 1년 54만원 (2인 등록)
미션 깨면 4만원 현금으로 돌려줌
12월 한정. 끝나면 끝.
```

### 뷰티/미용실

#### 신규 고객
```
"첫 방문이세요?"
신규 고객 50% 할인
예약 폭주 중. 자리 없으면 끝.
```

#### 친구 동반
```
친구랑 오면 둘 다 30% 할인
혼자 오면 손해입니다
이번 달만. 다음 달 없음.
```

#### 시술 강조
```
"매직? 염색? 다 포함입니다"
올인원 패키지 99,000원
정가 20만원짜리. 이번 달만.
```

### 음식점/카페

#### 오픈 기념
```
"오픈 기념, 미친 가격"
전 메뉴 50% 할인
선착순 100명. 그 다음은 없음.
```

#### 단체 할인
```
4인 이상 오면 1인분 무료
예약 필수. 자리 없으면 웨이팅
오픈 한 달만. 서두르세요.
```

#### 리뷰 이벤트
```
리뷰 쓰면 음료 무료
별점 5점이면 디저트까지
사진 올리면 다음 방문 20% 할인
```

### 학원/교육

#### 무료 체험
```
"1주일 무료로 들어보세요"
맘에 안 들면 그냥 가세요
등록 강요? 절대 없음.
```

#### 성적 보장
```
"3개월 안에 성적 안 오르면?"
100% 환불해드립니다
그만큼 자신 있습니다.
```

#### 친구 동반
```
친구랑 같이 등록하면
둘 다 50만원 할인
같이 공부하면 더 오래 갑니다
```

### 숙박/펜션

#### 비수기 특가
```
"평일에 오세요. 반값입니다"
일~목 50% 할인
이 가격에 이 뷰? 지금뿐.
```

#### 연박 할인
```
2박 하면 1박 반값
3박 하면 1박 무료
길게 쉬세요. 그래야 진짜 휴식.
```

#### 얼리버드
```
한 달 전 예약하면 40% 할인
일주일 전? 10%만.
빨리 잡는 사람이 이깁니다.
```

## 후킹 작성 공식

### 1. 손실 회피 (FOMO)
```
"~하면 손해입니다"
"이 가격 다신 없습니다"
"끝나면 끝."
"선착순 ___명"
```

### 2. 숫자 임팩트
```
정확한 가격 제시
할인 금액 명시
기간 한정 강조
```

### 3. 감정 자극
```
"~? 같이 하면 달라집니다"
"새해 첫 약속"
"혼자 세우지 마세요"
```

### 4. 직설적 표현
```
"끝나면 끝"
"없으면 웨이팅"
"다음 달 없음"
```

### 5. 질문형
```
"~이세요?"
"~할 수 있나요?"
"왜 혼자 가세요?"
```

## 전단지 3줄 구성

```
[1줄] 강렬한 후킹 (질문/충격/공감)
[2줄] 핵심 혜택 (가격/할인/무료)
[3줄] 행동 유도 (기간/한정/연락처)
```

### 예시
```
"혼자 등록하면 손해입니다"          ← 후킹
친구랑 오면 월 45,000원 + 4만원 캐시백   ← 혜택
12월 한정. 010-0000-0000           ← 행동 유도
```
