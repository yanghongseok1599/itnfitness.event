# 빠른 시작 가이드

## 새 랜딩페이지 만들기

### 1. 프로젝트 생성
```bash
npx create-next-app@latest [프로젝트명] --typescript --tailwind --eslint --app --src-dir --no-turbo --import-alias "@/*" --use-npm
cd [프로젝트명]
npm install framer-motion react-icons next-sitemap
```

### 2. 필요 정보 준비
```
- 브랜드명:
- 이벤트명:
- 이벤트 기간: YYYY.MM.DD ~ YYYY.MM.DD
- 슬로건/카피:
- 상품/서비스 가격:
  - 상품1: 원
  - 상품2: 원
- 할인 조건:
- 미션/이벤트 내용:
- 연락처:
- 주소:
- 운영시간:
- 카카오톡 채널:
- 네이버 플레이스:
```

### 3. 에셋 준비
```
public/
├── og-image.png      (1200x630, SNS 공유용)
├── favicon.ico       (파비콘)
├── logo.png          (로고)
├── hero-bg.mp4       (히어로 배경 동영상, 선택)
├── facility.jpg      (시설 이미지)
└── product.jpg       (상품 이미지)
```

### 4. 클로드에게 요청하기
```
docs/landing-page-skill.md 파일을 참고해서
[업종] 이벤트 랜딩페이지를 만들어줘.

브랜드명: xxx
이벤트: xxx 신년 이벤트
기간: 2025.01.01 ~ 2025.01.31
혜택:
  - 12개월 등록 시 월 50,000원
  - 2인 등록 시 월 45,000원
미션: 카카오톡 친추, 네이버 저장 시 각 1만원 할인
연락처: 010-0000-0000
주소: xxx시 xxx구 xxx로 00
운영시간: 06:00 - 23:00
카카오톡: https://pf.kakao.com/xxx
네이버: https://naver.me/xxx
```

### 5. Google Sheets 연동 (선택)
1. Google Sheets 새 문서 생성
2. 확장 프로그램 > Apps Script
3. docs/google-apps-script.js 내용 복사
4. 배포 > 새 배포 > 웹 앱
5. 액세스: 모든 사용자
6. URL 복사 후 Vercel 환경변수에 추가

### 6. 배포
```bash
npx vercel --prod
```

## 업종별 커스터마이징

### 피트니스/헬스장
- 회원권 가격표
- 2인 동반 할인
- PT 프로그램 소개
- 트레이너 소개
- 시설 이미지

### 뷰티/미용실
- 시술 메뉴판
- 신규 고객 할인
- 스타일리스트 소개
- 포트폴리오 갤러리

### 음식점/카페
- 메뉴판
- 오픈 기념 이벤트
- 위치/주차 안내
- 예약 폼

### 학원/교육
- 강좌 안내
- 강사 소개
- 수강료
- 상담 신청 폼

### 숙박/펜션
- 객실 안내
- 요금표
- 시설 갤러리
- 예약 캘린더

## 자주 사용하는 수정 요청

### 색상 변경
```
메인 컬러를 green에서 blue로 바꿔줘
```

### 섹션 추가
```
갤러리 섹션 추가해줘
```

### 가격 수정
```
월 45,000원을 월 39,000원으로 바꿔줘
```

### 연락처 변경
```
전화번호를 010-1234-5678로 다 바꿔줘
```

### 배경 동영상 추가
```
히어로 섹션 배경에 /video.mp4 불투명도 40%로 재생해줘
```

### 배포
```
배포해줘
```
